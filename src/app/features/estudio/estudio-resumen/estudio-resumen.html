Cómo se contrastaron las hipótesis (SPSS 29)

  1. Se usa un valor por sesión de cada indicador (hoja SPSS_Independientes del Excel).
  2. Normalidad de cada etapa con Shapiro-Wilk (13 sesiones por etapa, n ≤ 50).
  3. Si ambas etapas son normales: t de Student para muestras independientes (previa prueba de Levene). Si no: U de Mann-Whitney.
  4. Significación unilateral con α = 0,05: un valor p menor que 0,05 rechaza la hipótesis nula.
